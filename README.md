# aether-go
A pluggable, graph-based workflow engine implementing the Graph Workflow Protocol — composable templates, DAG orchestration, conditional branching, loop primitives, pluggable executors , retry &amp; timeout policies, and cron scheduling.

## Protocol documentation

The protocol Schema and HTML reference are maintained in [aether-spec](https://github.com/BabySid/aether-spec).

- [Documentation entry](https://github.com/BabySid/aether-spec/blob/main/index.html)
- [Schema reference](https://github.com/BabySid/aether-spec/blob/main/docs/schema.html)
- [JSON Schema](https://github.com/BabySid/aether-spec/blob/main/schema/v1/graph-schema.json)

Clone `aether-spec` and open `index.html` in a browser for offline reading. GitHub displays the HTML source; a hosted documentation site is not configured.
